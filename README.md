# HK Case Law Monitor v.1.0

Частный некоммерческий инструмент поиска и мониторинга судебной практики Гонконга (private study and research).

- **index.html** — инструмент целиком (GitHub Pages): метапоиск по базам (LRS, hkcfa.hk, HKLII, vLex, Westlaw HK, Lexis+ HK), RSS-мониторинг LRS с профилями поиска и e-mail-рассылкой, анализ загруженных решений (PDF/DOCX/HTML/TXT), справочник источников.
- **hk_caselaw_server.py** — локальный сервер для мониторинга и рассылки (Python 3.8+, только стандартная библиотека). Тот же файл скачивается со страницы, вкладка «7. Установка».

Запуск сервера: `python3 hk_caselaw_server.py`, затем открыть http://127.0.0.1:8767/

Ограничения: тексты решений не скачиваются; HKLII автоматически не опрашивается (политика HKLII); robots.txt legalref.judiciary.hk (на 27.10.2026: `User-Agent: *` / `Disallow: /`) — опрос RSS-лент LRS только после явного решения оператора в интерфейсе.
