Дела на контроле

Программа сверяет каждое новое решение из лент и каждый загруженный документ с делами на контроле (номер дела, NCN, стороны, ключевые слова) и записывает события в хронологию. Новые события подсвечиваются, о них приходят уведомления и письма.

Выберите дело слева или поставьте новое на контроль.

Документы и анализ

Загрузите решения (PDF, DOCX, HTML, TXT), сохранённые вручную с LRS, HKLII или из подписочных баз. Программа извлекает суд, NCN, номер дела, дату и состав, связывает документ с делами на контроле и ищет термины. Документы хранятся только на этом компьютере.

Перетащите файлы сюда или нажмите для выбора

Профили поиска

Критерии отбора решений из лент и документов. Без учёта регистра; термины от 6 символов устойчивы к разрывам слов в PDF. Слова — через «;» или с новой строки.

Рассылка

Дайджест новых решений по профилям, письма об изменениях по делам на контроле, отчёты анализа документов.

SMTP

Gmail: smtp.gmail.com, 465, SSL, логин — адрес Gmail, пароль — пароль приложения Google. Пароль хранится на этом компьютере в зашифрованном виде (Windows DPAPI).

Автоматизация

Цикл: проверка лент → сверка с делами на контроле → напоминания → письмо об изменениях по делам → дайджест. Работает, пока программа запущена (в окне или в области уведомлений). Задача в Планировщике заданий Windows запускает цикл, даже если программа закрыта. Права администратора не нужны.

ИИ-помощник

Подключение языковых моделей по API: Claude (Anthropic), ChatGPT (OpenAI) или любой OpenAI-совместимый сервис (DeepSeek, OpenRouter, Mistral, локальные Ollama и LM Studio). Используется для резюме решений, извлечения данных, ответов на вопросы по тексту, подбора терминов и справок по делам. Все ответы ИИ помечаются как требующие проверки.

Ключ хранится на этом компьютере в зашифрованном виде (Windows DPAPI). Тексты документов уходят внешнему сервису только при включённом согласии; для локальных моделей (Ollama, LM Studio) данные не покидают компьютер.
