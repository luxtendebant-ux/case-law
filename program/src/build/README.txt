1. ЧТО ДЕЛАЕТ ПРОГРАММА
- Поиск: один запрос во все базы судебной практики Гонконга (LRS, hkcfa.hk, HKLII, vLex, Westlaw, Lexis+, свои источники) и в собранную программой базу.
- Мониторинг: официальные RSS-ленты Legal Reference System по судам, отбор решений по профилям поиска.
- Дела на контроле: программа сверяет каждое новое решение и каждый загруженный документ с вашими делами (номер дела, NCN, стороны, ключевые слова), ведёт хронологию, напоминает о сроках, присылает письма об изменениях.
- Документы: загрузка решений (PDF, DOCX, HTML, TXT), извлечение суда, NCN, номера дела, даты, состава, поиск терминов, отчёты.
- ИИ-помощник: Claude, ChatGPT или любой OpenAI-совместимый сервис (в т.ч. локальные Ollama, LM Studio) — резюме решений для руководства, извлечение данных, вопросы к тексту, подбор терминов.
- ИИ-агент: MCP-сервер, REST API с токеном, вебхуки, командная строка, журнал аудита.
- Автоматизация: расписание внутри программы, задача в Планировщике заданий Windows, автозапуск.

2. ТРЕБОВАНИЯ
Windows 10 или 11, 64 бит. Права администратора не нужны. Python и все компоненты встроены.
Собственное окно программы использует Microsoft Edge WebView2 Runtime (в Windows 11 есть всегда; в Windows 10 обычно есть). Если его нет, программа предложит установить его и пока откроется в браузере.
Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

3. ПЕРВЫЕ ШАГИ
1) «Мониторинг лент»: добавьте нужные ленты со страницы подписки LRS (legalref.judiciary.hk/lrs/common/rss/subscribe.jsp). Лента CFA уже добавлена.
2) robots.txt сайта LRS запрещает программам автоматический доступ (на 27.10.2026). Опрос ленты включается только вашим решением — отметка «Допускаю опрос».
3) «Профили поиска»: задайте слова для отбора решений.
4) «Рассылка»: SMTP (для Gmail — пароль приложения Google) и получатели; «Тестовое письмо».
5) «Дела на контроле»: поставьте дела на контроль (или кнопка «На контроль» у решения).
6) «Автоматизация»: расписание; задача Windows и автозапуск.

4. ПОДКЛЮЧЕНИЕ ИИ-АГЕНТА
- MCP (Claude Desktop): Настройки → Developer → Edit Config, добавьте фрагмент из раздела «ИИ-агент» программы:
  {"mcpServers": {"hk-case-law": {"command": "<папка программы>\\hkcl.exe", "args": ["mcp"]}}}
- Claude Code:  claude mcp add hk-case-law -- "<папка программы>\hkcl.exe" mcp
- REST API: http://127.0.0.1:8767/api/v1, заголовок Authorization: Bearer <токен из раздела «ИИ-агент»>; спецификация: /api/v1/openapi.json
- Командная строка: hkcl.exe --help  (status, check, cycle, digest, search, links, cases, doc, token, openapi, schedule, autostart, shutdown)
- Права агента и журнал аудита — раздел «ИИ-агент».

5. ГДЕ ДАННЫЕ
%APPDATA%\HKCaseLawMonitor — настройки, база (SQLite), документы, журналы. Пароли и ключи зашифрованы (Windows DPAPI).
Резервная копия: «О программе» → «Резервная копия».

6. УДАЛЕНИЕ
Любой из способов:
- в программе: «О программе» → «Удалить программу…»;
- «Параметры Windows» → «Приложения» → HK Case Law Monitor → «Удалить»;
- меню «Пуск» → HK Case Law Monitor → «Удалить HK Case Law Monitor»;
- командная строка: hkcl.exe uninstall (с ключом --silent — без вопросов, данные сохраняются).
Программа останавливается автоматически; удаляются файлы программы, ярлыки, задача Планировщика заданий и автозапуск. Данные пользователя удаляются только по вашему подтверждению.

Программа не является юридической консультацией. Результаты ИИ требуют проверки. Итоговые решения принимает оператор.
